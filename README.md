# 📊 Telecom Customer Churn Analysis Dashboard

## 📌 Overview

The Telecom Customer Churn Analysis Dashboard is a Power BI project designed to analyze customer churn behavior and provide actionable insights for customer retention. The dashboard helps businesses identify patterns, trends, and factors influencing customer attrition, enabling data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze customer churn trends and patterns.
- Identify key factors contributing to customer attrition.
- Monitor customer retention and engagement metrics.
- Evaluate service usage and customer demographics.
- Support strategic business decisions through interactive visualizations.

---

## 🛠️ Technologies Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 📈 Dashboard Features

### 1. Home Page
- Project overview
- Navigation panel
- Dashboard introduction

### 2. Summary Dashboard
Provides a complete overview of:

- Total Customers
- Active Customers
- Churned Customers
- Churn Rate
- Revenue Metrics
- Customer Demographics
- Service Usage Analysis
- Retention Insights

### 3. Ask a Question
- Power BI Q&A feature
- Enables users to ask questions in natural language and receive instant visual insights

## 🚀 How to Run the Project

1. Download the `.pbix` file from this repository.
2. Open the file using Microsoft Power BI Desktop.
3. Refresh the data if required.
4. Explore the dashboard using filters and slicers.
5. Use the Q&A section to generate custom insights.
